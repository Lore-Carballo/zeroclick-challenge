01

Designed for a moving system

Zero Click lives at a moment of transition: from searching to asking, from links to answers, from a predictable funnel to a system that is still taking shape.

The identity turns that state of change into a visual language. Rather than creating a completely separate world from Profound, I expanded its existing system through movement, changing states, coded information and a broader color palette.

02

A timestamp for an evolving system

Every Zero Click event captures the state of an industry at a particular moment, in a particular place.

'Bitcount Grid Single' font is used for dates, locations, numbers and event data. It gives each event the feeling of a timestamp, a coordinate or a captured state within a larger evolving system.

03

Movement as a visual language

Motion is not treated as decoration. It helps express how information behaves in a conversational system: text resolves into data, language appears as if it is being written in real time, and interfaces shift from one state to the next.

The existing Profound bitmap language is extended through texture, scale and color, turning familiar assets into more expressive surfaces for Zero Click while remaining connected to the core brand.

  • Expanded for Zero Click

    • State-based motion
    • Event codes and timestamps
    • A more expressive editorial system
04

Distinct, not disconnected

Zero Click needed more independence to feel like an event brand, without losing the equity of Profound.

The result is less a sub-brand built beside Profound, and more an event layer built on top of it.

05

The website

The existing Zero Click site functioned primarily as an event page. The redesign turns it into a persistent home for the series, while remaining intentionally close to Profound's product and marketing ecosystem.

The UX was structured around the full event lifecycle: discovering the series, scanning key information, exploring upcoming events, and revisiting past sessions and content. I also introduced a few lightweight UX/UI refinements, including filters, clear status tags, and color coding to make events states easier to identify at a glance.

Rather than rebuilding the UI language from scratch, I reused and adapted patterns from Profound’s current website, keeping navigation, typography, spacing and interactions familiar while giving Zero Click a stronger event identity.
